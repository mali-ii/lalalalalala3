# Практическое занятие 6 — готовые материалы

В `docs/` находятся Product Backlog, Sprint Backlog, Kanban-доска, заметки стендапа и ретроспектива. В `shop.py` приведена реализация четырёх функций и аналитики категорий.

## Контрольные вопросы

1. **Чем Scrum отличается от Kanban?** Scrum организует работу фиксированными спринтами с ролями и регулярными событиями. Kanban управляет непрерывным потоком задач через визуальную доску и WIP-лимиты.
2. **Что такое User Story и критерии приёмки?** User Story — краткое описание потребности пользователя и её ценности. Критерии приёмки задают проверяемые условия, которым должен соответствовать готовый результат.
3. **Зачем нужны Story Points?** Они позволяют сравнительно оценивать сложность и объём историй для планирования ёмкости спринта; это относительная оценка, а не точное число часов.
4. **Что такое WIP-лимит?** Это ограничение числа задач в работе одновременно. Оно помогает не перегружать команду и быстрее доводить начатое до завершения.
5. **Какие три вопроса задают на Daily Standup?** Что сделано? Что планируется? Какие есть препятствия?
6. **Что такое ретроспектива?** Встреча для улучшения процесса после итерации. Обсуждают, что прошло хорошо, что улучшить и что попробовать в следующем спринте.

## Коммиты в проекте SportShop

После переноса `shop.py` и файлов `docs/` в корень вашего проекта можно зафиксировать минимум три коммита:

```bash
git add shop.py docs/03_Product_Backlog.md docs/04_Sprint_Backlog.md
git commit -m "US-1: добавлена обработка товаров с низким остатком"
git add docs/05_Kanban_Board.md docs/06_Standup_Notes.md
git commit -m "US-2: добавлен поиск и обновлена доска спринта"
git add docs/07_Retrospective.md README.md
git commit -m "US-4: добавлено сохранение отчёта занятия"
```

Это команды для запуска в репозитории; ссылки на фактические коммиты появятся после их создания.
